# Публикация сайта: с нуля до рабочего домена

Инструкция рассчитана на то, что вы никогда не работали с Git и GitHub.
Делайте по порядку — каждый шаг проверяемый.

Что понадобится:

- аккаунт **GitHub** (бесплатный);
- **Git** для Windows (или GitHub Desktop — проще, см. шаг 3);
- домен на **reg.ru**;
- хостинг на **reg.ru** (или любой другой с FTP и поддержкой `.htaccess`);
- **FileZilla** — бесплатная программа для загрузки файлов по FTP.

---

## Часть 1. GitHub: аккаунт и репозиторий

### Шаг 1. Регистрация

1. Откройте https://github.com/signup
2. Введите почту, пароль, придумайте **username** (латиницей, например `forsaj-mk`). Username станет частью адреса репозитория.
3. Подтвердите почту по письму от GitHub.
4. В настройках профиля (`Settings → Public profile`) можно поставить имя и аватар — не обязательно.

> Почему GitHub, а не «папка на диске»: это резервная копия в облаке, история изменений
> и возможность откатиться, если что-то сломается. Плюс с этого аккаунта потом можно
> подключить автоматическую публикацию.

### Шаг 2. Установить Git

1. Скачайте https://git-scm.com/download/win и установите (все галочки по умолчанию подходят).
2. Проверьте в PowerShell:

```powershell
git --version
```

3. Представьтесь Git'у (один раз):

```powershell
git config --global user.name "Ваше Имя"
git config --global user.email "почта@из-github"
```

### Шаг 3. Создать репозиторий

1. На GitHub: **New repository** (https://github.com/new).
2. Имя: `forsaj-site`.
3. Видимость: **Private** (сайт всё равно увидят все — репозиторий с кодом видят только вы).
4. Не ставьте галочки «Add README», «Add .gitignore» — репозиторий должен быть пустым.
5. **Create repository**. GitHub покажет адрес вида `https://github.com/ВАШ-ЛОГИН/forsaj-site.git`.

### Шаг 4. Залить сайт

> **Важно:** локальный репозиторий уже создан — 45 файлов, первый коммит в ветке `main`.
> `git init`, `git add` и `git commit` повторять **не нужно**, начинайте сразу с `git remote add`.

**Вариант А — через командную строку (быстрее).**

```powershell
cd "C:\Users\MSI\OneDrive\Документы\deepseek-harness\default-workspace\forsaj-site"

git remote add origin https://github.com/ВАШ-ЛОГИН/forsaj-site.git
git push -u origin main
```

При `git push` Git Credential Manager предложит войти. Порядок действий:

1. В появившемся окне выберите **Sign in with your browser** (вход через браузер).
2. Откроется браузер, войдите в свой аккаунт GitHub и нажмите **Authorize**.
3. Вернитесь в PowerShell — пароль не нужен, токен Git сохранит сам.

Если окно с браузером не появилось и просит логин/пароль — пароль от аккаунта не подойдёт,
нужен **Personal Access Token**:

1. GitHub → `Settings` → внизу `Developer settings` → `Personal access tokens` → `Tokens (classic)`.
2. `Generate new token (classic)`, срок — 90 дней, галочка **`repo`**.
3. Скопируйте токен (он показывается один раз) и вставьте вместо пароля.

Windows запомнит токен, второй раз вводить не придётся.

**Вариант Б — через GitHub Desktop (без командной строки).**

1. Скачайте https://desktop.github.com и войдите своим аккаунтом.
2. `File → Add local repository…` → укажите папку `forsaj-site`.
3. Он предложит создать репозиторий — согласитесь, затем нажмите **Publish repository**
   (галочку «Keep this code private» можно оставить).

### Шаг 5. Проверка

Обновите страницу репозитория на GitHub — там должны быть `index.html`, `assets/` и остальное.
В дальнейшем после любой правки:

```powershell
git add .
git commit -m "что изменил"
git push
```

Или в GitHub Desktop: слева список изменённых файлов → поле «Summary» → **Commit to main** → **Push origin**.

## Часть 2. Домен и хостинг на reg.ru

### Шаг 1. Купить домен

1. https://www.reg.ru/ → введите желаемое имя → **Купить**.
2. Зона `.ru` — около 200–300 ₽ за первый год (продление дороже). Оплатите.
3. Домен появится в личном кабинете в разделе **Домены**.

Не берите «парковку», «хостинг сайта-визитки у регистратора» и прочие платные допы —
достаточно домена + обычного хостинга.

### Шаг 2. Заказать хостинг

1. Личный кабинет → **Хостинг** → выбрать тариф. Для статического сайта хватает самого
   дешёвого (обычно «Хостинг-1»). Не нужен ни VPS, ни выделенный сервер.
2. При заказе укажите домен, который купили — он сразу привяжется к хостингу.
3. После активации в разделе **Хостинг → Управление** будет:
   - **сервер FTP**: `ftp.ваш-домен.ru`, логин вида `ваш-домен.ru`, пароль;
   - **IP-адрес**;
   - **корневая папка** — обычно `/www/ваш-домен.ru/`.

### Шаг 3. Привязка домена

Если домен и хостинг куплены в одном аккаунте reg.ru — привязка происходит автоматически
(домен указывает на NS reg.ru). Проверьте: **Домены → ваш домен → DNS-серверы** должны быть
`ns1.reg.ru` и `ns2.reg.ru`.

Если домен регистрировался отдельно — в **DNS-серверы** домена прописываются NS вашего
хостинга, либо A-запись с IP хостинга.

Обновление DNS занимает от 15 минут до 24 часов.

### Шаг 4. Загрузить файлы

1. Установите FileZilla: https://filezilla-project.org/download.php?type=client
2. `Файл → Менеджер сайтов → Новый сайт`:
   - Хост: `ftp.ваш-домен.ru`
   - Пользователь / пароль: из панели хостинга
   - **Create** → **Connect**
3. В правой части (сервер) откройте папку сайта — та, где лежат `index.html`, `assets`,
   `.htaccess` (обычно `/www/ваш-домен.ru/`). Содержимое стартовой папки можно удалить
   (обычно там `index.html`-заглушка хостинга).
4. В левой части (компьютер) откройте папку `forsaj-site`.
5. Выделите **содержимое** папки (не саму папку!) и перетащите вправо. `.htaccess` включительно —
   в FileZilla включите `Сервер → Принудительно показывать скрытые файлы`, иначе он не виден.

Через 1–2 минуты откройте `http://ваш-домен.ru`.

> Альтернатива FTP — **SSH/SFTP**: в панели reg.ru можно включить SSH и заливать по `scp`.
> Но для старта FileZilla проще.

### Шаг 5. Включить HTTPS

1. Панель хостинга → **SSL-сертификаты** → выпустить бесплатный **Let's Encrypt** для домена
   (и для `www.`).
2. Дождитесь статуса «Активен» (5–30 минут).
3. Включите опцию **«Перенаправлять HTTP на HTTPS»**, если она есть.

После этого сайт открывается по `https://ваш-домен.ru`, в адресной строке — замок.

### Шаг 6. Проверка после публикации

- [ ] `https://ваш-домен.ru` открывается, картинки и шрифты на месте;
- [ ] `https://ваш-домен.ru/contacts.html` и `.../map.html` работают;
- [ ] карта на странице «Как проехать» показывает точку на Берёзовой аллее;
- [ ] клик по номеру на телефоне открывает звонок, кнопка WhatsApp открывает чат;
- [ ] `https://ваш-домен.ru/forsaj` перекидывает на главную (редирект);
- [ ] в `index.html` не осталось заглушки `forsaj-mk.ru` — вы запускали `python set_domain.py`.

## Часть 3. Мелкие, но важные дела

### Обновить ссылку в Яндекс.Бизнесе

Если карточка организации в Яндекс.Картах ссылается на старый сайт — поменяйте в
Яндекс.Бизнесе (https://business.yandex.ru) на новый домен. То же для 2ГИС и соцсетей.

### Добавить сайт в Яндекс.Вебмастер

1. https://webmaster.yandex.ru → **Добавить сайт** → ваш домен.
2. Подтвердите права: проще всего файлом — Вебмастер даст `.html`-файл, положите его
   в корень через FileZilla.
3. В разделе «Индексирование → Файлы Sitemap» добавьте `https://ваш-домен.ru/sitemap.xml`.

### Что будет со старым сайтом

`peachauto.ru/forsaj` — чужой домен, вы на него не влияете и трогать не нужно.
Новый сайт живёт отдельно. Если на старые адреса где-то стоят ссылки (визитки, QR, карточки
в картах) — обновите их, а на новом домене старые адреса `/forsaj`, `/forsaj_info`,
`/forsaj_map` и так перенаправляются на новые страницы.

### Как менять сайт дальше

1. Правите файлы в папке `forsaj-site` (как — описано в [README.md](README.md)).
2. `git add . && git commit -m "правка" && git push` — история и бэкап в GitHub.
3. В FileZilla заново перетаскиваете изменённые файлы.

Когда надоест заливать вручную — можно настроить GitHub Actions (файл `.github/workflows/deploy.yml`),
чтобы сайт уезжал на хостинг сам при каждом `push`. Это отдельный шаг, скажите — сделаю.

# FORSAJ МК — сайт мультибрендового автоцентра

Статический сайт из трёх страниц: услуги, контакты, как проехать. Без Tilda, без базы данных,
без сборки — обычные HTML/CSS/JS. Можно открыть двойным кликом, а можно залить на любой хостинг.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Главная: hero, 6 направлений, дополнительные услуги, CTA |
| `contacts.html` | Телефоны, WhatsApp, адрес, график и живой статус «открыто/закрыто» |
| `map.html` | Карта, 4 шага «как найти», галерея фото ориентиров с зумом |
| `404.html` | Страница «не найдено» |
| `assets/css/style.css` | Все стили (одним файлом, с комментариями) |
| `assets/js/app.js` | Режим работы, лайтбокс, подсветка меню, анимации появления |
| `assets/fonts/` | Unbounded + Montserrat, локально (не зависит от Google Fonts) |
| `assets/img/` | Фото ориентиров, OG-картинка для соцсетей, иконки |
| `forsaj/`, `forsaj_info/`, `forsaj_map/` | Заглушки-редиректы со старых адресов Tilda |
| `robots.txt`, `sitemap.xml` | Для поисковиков |
| `.htaccess` | Редиректы, сжатие, кэш, заголовки безопасности (Apache/reg.ru) |
| `set_domain.py` | Подставляет настоящий домен вместо заглушки |

## Как посмотреть локально

Вариант 1 — просто открыть `index.html` в браузере (частично работает, но карта и шрифты
надёжнее через сервер).

Вариант 2 — мини-сервер:

```powershell
# в папке forsaj-site
python -m http.server 8000
```

и открыть http://127.0.0.1:8000

## Что и где править

### Телефоны и WhatsApp

Номер `+7 977 378-73-24` встречается в трёх файлах (`index.html`, `contacts.html`, `map.html`)
в двух видах: для отображения `+7 977 378-73-24` и для ссылки `tel:+79773787324`,
а WhatsApp — `https://wa.me/79773787324`.

Проще всего: «Найти и заменить» по всей папке (в VS Code — Ctrl+Shift+H):
- `+79773787324` → новый номер без пробелов
- `+7 977 378-73-24` → новый номер с пробелами
- `+79935895667` / `+7 993 589-56-67` → второй номер (только `contacts.html` и футеры)

### Адрес, график, координаты

- Адрес: `Берёзовая аллея, 4` и `Москва, район Отрадное` — в тексте страниц и в JSON-LD (`index.html`, блок `<script type="application/ld+json">`).
- График 10:00–22:00 задаётся в трёх местах: тексты на страницах, разметка `.schedule` в `contacts.html` и константы в `assets/js/app.js`:
  ```js
  var OPEN_HOUR = 10;
  var CLOSE_HOUR = 22;
  ```
- Координаты карты: `55.851965, 37.610020` — в `map.html` в ссылке карты (`ll`, `pt`, `rtext`) и в JSON-LD.

### Услуги

Шесть карточек — это блоки `<article class="service">` в `index.html`. Внутри:
- `<h3 class="service__title">` — название;
- `panel service__desc` — «Что это за услуга»;
- `<ol class="steps steps--cols">` — «Как осуществляется процедура».

Скопируйте карточку и поменяйте текст, чтобы добавить седьмое направление. Номер (`01`, `02`…)
задаётся вручную в `<span class="service__num">`.

### Фото

`assets/img/orientir-1-vjezd.jpg`, `orientir-2-povorot.jpg`, `orientir-3-fasad.jpg` — скачаны
с текущего сайта (там они лежали в чужом облаке Mail.ru). Рекомендую заменить своими
оригиналами в хорошем качестве: просто положите файлы с теми же именами.

`og-image.jpg` — картинка-превью для соцсетей и мессенджеров (1200×630). Если поменяете
телефон на сайте — поменяйте и её.

## Как поставить настоящий домен

Сейчас в `canonical`, `og:url` и `sitemap.xml` стоит заглушка `forsaj-mk.ru`. Когда купите домен:

```powershell
python set_domain.py ваш-домен.ru
```

Скрипт заменит заглушку во всех HTML, в `sitemap.xml` и `robots.txt`.

## Технические заметки

- Никаких внешних зависимостей: шрифты, стили, скрипты — всё своё и локальное.
- Тёмная тема, красный акцент `#ff003c`, шрифты Unbounded (заголовки) и Montserrat (текст).
- Нижний «док» с диодами виден только на мобильных; на десктопе навигация в шапке.
- Учитывается `prefers-reduced-motion` — анимации отключаются для тех, кто так просил в системе.
- Проверено в Chromium (Edge) на 1440 px и 390 px.
